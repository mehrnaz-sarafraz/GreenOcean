# Content safety policy contract — implementation draft, activation approval outstanding

Supportive expression, pain, distress, anger and descriptions of victimization are permitted. Harassment, humiliation, hate, threats, sexual harassment, doxxing, spam, dangerous encouragement and coercion require proportionate restrictions. This is a non-clinical peer community; screening is not diagnosis or emergency supervision.

Local ContentClassifier interface processes only bounded post/comment text. ContentSafety local-screen-v1 normalizes a matching copy (NFKC, Arabic letter variants, marks/format characters, whitespace); original Persian, ZWNJ and emoji remain unchanged. Simple contextual indicators distinguish certain quoted/negated threats from direct patterns. Unknown suspicious cases/links/private-information patterns/confusables go HOLD_FOR_REVIEW; direct recognized harmful encouragement/threats BLOCK_PROHIBITED; recognized targeted insults/promotion REQUEST_REVISION; no matched signal ALLOW. No external provider receives text. All modified post bodies are screened again.

**Limits:** absence of a pattern is not proof of semantic safety. This local rules implementation can miss hate, sexual harassment, nuanced coercion, transliteration, homoglyphs, codewords, idioms and indirect threats. It can over-hold quotations, figurative expressions, safe links and numbers. Bilingual examples test concrete behavior, not accuracy across an unknown population. No100% detection claim. Staff review/report/takedown, approved policy, escalation and the default-off publication gate remain necessary. An approved stronger local classifier can implement the same interface; external AI requires separate privacy/owner authorization.

Classifier runtime failure becomes private pending SCREEN_UNAVAILABLE. If persistence/queue evidence cannot commit, the transaction fails, no unchecked publication occurs and the client keeps unsent text. No unbounded retry, secret regex explanations or story bodies in routine logs. Final policy wording and evidence retention/escalation obligations require actual owner/legal/operations approval before activation.
