# Exact revision educational review
DRAFT → SUBMITTED → APPROVED → PUBLISHED. Independent review may instead choose NEEDS_REVISION or REJECTED. Only DRAFT text is editable. Revising submitted/rejected/published content creates a new immutable version identity and clears its approval; optimistic etags prevent stale draft overwrites. The previous approved publication stays available while a new draft is reviewed. A review must target the current exact version and etag, with actual source and copyright checks, reviewer, reason and server timestamp. The author cannot approve their own content.
Publication rechecks current author/reviewer grants and specialist credentials, requires an independently approved exact revision and the separate default-off publication-approved flag. Featuring is independently authorized; retirement removes active recommendation and preserves an unavailable private-save tombstone that its owner can remove. Editorial action history contains scope-limited notes, not copied private journals or post narratives. Baseline V29 already removed the development article/media fixtures; any persisted legacy article/media rows and saves are preserved unchanged at upgrade; wrappers mark them LEGACY_UNREVIEWED and compatible catalog reads refuse their unverified claims. Their remediation needs a new properly attributed reviewed revision, never a fabricated retrospective approval.
