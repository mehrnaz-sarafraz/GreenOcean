# For Further Reading privacy
Old posts begin without an opt-in. Only the original author can enable/revoke a per-post preference or remove an association, with a revision. Changing that preference removes old pending/approved associations. Proposers need current post access, explicit ATTACH scope and a currently reviewed published resource. A staff reviewer with current REVIEW/APPROVE scope, recent MFA and their own legitimate post access independently checks the association. This grants no group membership or follower relationship.
Publication is bound to exact post/resource/preference revisions. Reads use the existing PostService audience/block/moderation/group checks; stale revisions, inaccessible/removed posts, author revocation and retired/unavailable resources are not recommended. Group locks precede post mutation locks, followed by a fresh access check. No post narrative is copied into library search or unrelated review events. Public attachment DTOs contain association/resource metadata, never original post author IDs or anonymous identity. Restricted audiences receive no staff/editor exception. Neutral educational wording does not diagnose the post author, rewrite their content or start private contact.
