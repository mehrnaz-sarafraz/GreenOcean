# Reviewed course and lesson model
Existing guided_growth_paths is the compatible course catalog, extended by a resource_id link to the exact-reviewed Growth Library. Immutable resource versions contain real ordered modules and lessons; learning_lesson_identities assigns server-owned stable lesson keys within one curriculum. A course has language, objectives, adult suitability, sources/rights, scope, exact author/reviewer approval and honest estimates. Bounded canonical structure allows at most twelve modules and fifty actual lessons, with required lessons and optional REFLECTION/CHECKLIST/CHOICE activities. No declared count creates placeholder lessons.
Current lesson bodies, objectives, activity and revision digests are served from the same reviewed structure used by PostgreSQL learning_lessons. Course publication derives the compatible catalog's actual lesson count and duration; current source eligibility/retirement governs availability. New publication and structured learning are separate default-off release gates. Legacy guided-path metadata remains stored but is not advertised as real reviewed lessons while it lacks a governed resource. No old percentage is converted to verified activity. The legacy_progress backfill uses the existing row-update trigger, so a legacy updated_at may reflect schema backfill; that timestamp is never treated as a new learning action or completion.
Draft English/Persian curricula in editorial-draft-curriculum.json are substantive original general-education material awaiting real attribution, source/rights and independent editorial review. They are not seeded or published, contain no fabricated clinician or approval, and do not promise treatment. Synthetic QA courses demonstrate the actual publication/learning pipeline without counting as production review.
