# Versioned optional daily reflection
Three currently published reviewed prompt versions are selected deterministically for an owner/local date. Selection and the actual prompt IDs persist; a reload or timezone change for that same date cannot replace the set. Dates derive from the database clock and a validated IANA zone. Different local dates may have sets, but neither answers nor missing days produce rewards. A set preserves its captured zone/language; historical answers join immutable question versions, including after retirement.
With fewer than three reviewed prompts in the selected language, the service reports unavailable instead of inventing review. Production ships no synthetic expert content or approvals. O2/O3 provide editorial governance; O1 integration fixtures use explicitly synthetic independent reviewers. Users may save zero to three answers, edit with a revision, delete and inspect private history. Typing alone makes no persistence request. Draft storage and answer purpose use the independent default-off sensitive-processing gate.
