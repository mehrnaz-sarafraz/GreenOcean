# Account rights integration
Reuse AccountService archive and AccountRepository erasure. privateWellbeing includes all owned journal/mood/goals/reflections, steps, selected prompt sets with exact question/answer versions, and only unexpired drafts. It is an own archive, not an endpoint for another member. Existing home snapshots stay bounded and are not advertised as complete history.
Erasure explicitly removes daily sets (cascading answers/selection) and drafts, alongside existing private records; steps cascade with goals. No new legal-hold exception is invented. Historical assessment answers and scores are retained without silent reclassification, while new UI avoids clinical conclusions. Production backup erasure limitations remain those in Phase J. New learning/catalog rights are added at their milestone.

O2 adds own educational submissions/revisions, grants, decisions, source saves and proposal records to the private archive. Erasure deletes authored resources and their saves/associations, removes own source saves/preferences/proposals, withdraws approvals issued by the erased reviewer, minimizes actor references and revokes affected educational permissions/credentials. There is no new invented permanent retention exception for an author's educational draft. Existing unrelated source metadata and another member's protected post never become the requester's export.

O3 adds all own lesson/course/exercise completions, latest pending lesson openings, original legacy learning metadata and own editorial question versions/review actions to the archive. No editor export includes another member's response. Creator erasure deidentifies compatible course authorship, deletes authored resource content, and preserves only the learner's own minimal historical milestones; deleting that learner removes those private records. Shared original prompt wording may remain deidentified and retired solely to preserve another owner's saved answer version. Production backup/retention/legal exceptions remain independently governed by J; no universal exception or deletion replay is invented.
