# Account rights integration
Reuse AccountService archive and AccountRepository erasure. privateWellbeing includes all owned journal/mood/goals/reflections, steps, selected prompt sets with exact question/answer versions, and only unexpired drafts. It is an own archive, not an endpoint for another member. Existing home snapshots stay bounded and are not advertised as complete history.
Erasure explicitly removes daily sets (cascading answers/selection) and drafts, alongside existing private records; steps cascade with goals. No new legal-hold exception is invented. Historical assessment answers and scores are retained without silent reclassification, while new UI avoids clinical conclusions. Production backup erasure limitations remain those in Phase J. New learning/catalog rights are added at their milestone.
