# Explicit pilot cohort and eligibility

`GREENOCEAN_PILOT_ENABLED=false`, source commit and owner IDs empty by default. No database row is enrollment or runtime enablement. External deployment configuration must supply the exact40-character deployed commit, designated owner UUIDs and explicit enablement only after independent authorization. `PILOT_OWNER` alone, ADMIN alone or CI alone confers no release power. Account platform authority requires strong current authentication.

Owner invitations are service-specific, limited to active verified adults whose residence and current country match the assessment. User accepts the current published optional notice; invitation or viewing a page never implies consent. Server scope, current source, current assessment, expiry and live dependency checks apply independently of client parameters. Distinct INVITED/ACCEPTED unexpired accounts are globally capped at100 by default (configurable100–500); transaction advisory locking prevents concurrent oversubscription. No recruitment was performed.

Once enabled, a sticky database enforcement marker prevents removing the environment flag from exposing an open service. Disable blocks new admission. Per-source guards cover group join/approval, public-profile viewing, follows and new direct-message requests/acceptance, publication, new self-care records, listener requests/queue/bookings/start/readiness, professional slot publication/booking, payment intent, new clinical entry/start and media admissions. Existing service/country/qualification/processing gates remain required.

Opt-out invalidates new admissions and cancels own waiting/offered queue and unstarted listener requests. A session already active keeps existing authenticated, consent and safety controls: listener pulse/end, clinical messages/end, record rights, cancellations/refunds and account export/deletion remain governed by their original controls. A fresh media credential remains a new admission and may require authorized care transition. Staff must arrange continuity and explain fallback before disabling a clinical service. Emergency containment remains in Q3; opt-out does not promise provider-wide disconnection.

Account archive includes only own participant/choice metadata and own authored release-evidence metadata; no other staff session identifiers. Pilot UI contains no new sensitive satisfaction questionnaire. Original retention/rights/holds remain applicable; no guessed clinical or financial deletion duration is activated.
