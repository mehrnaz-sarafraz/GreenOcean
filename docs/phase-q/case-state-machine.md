# Case transitions and concurrency

RECEIVED→TRIAGED/WAITING_FOR_OPERATOR; TRIAGED/WAITING→UNDER_REVIEW; UNDER_REVIEW→WAITING/ACTION_PENDING_APPROVAL; pending→TRIAGED (revoke) or ACTIONED; ACTIONED→RESOLVED/APPEALED; RESOLVED→CLOSED/APPEALED; CLOSED→APPEALED; APPEALED→APPEAL_REVIEW→ACTION_PENDING_APPROVAL. Each transition requires exact revision under a row lock and appends a unique revision event. Source import is unique and idempotent across backend instances. Unsupported transitions fail409.

Review admission requires acknowledged current shift/presence and bounded assigned capacity; assignments serialize by operator. Only the assigned reviewer proposes approval. Approval lasts15 minutes and binds the exact source-state/appeal snapshot and author session. A second current independent operator is required; author role/session/MFA must still be valid. No substantive source decision is performed by this coordinator. ACTIONED confirms an already finished authorized source outcome. Unresolved source or pending appeal cannot be marked completed; source changes invalidate approval/closure. Original decision makers cannot coordinate appeal review; existing source appeal controls remain authoritative. No new competing appeals table exists.

Source adapters take source-row transaction locks; approval and terminal changes re-read current source state. Safe projections never include the conflict identities used internally for independence. Coordinators who are source subjects/reporters are rejected. Case events contain no copied text. Database transaction budgets bound imports60/hour, transitions120/hour and staffing writes30/hour.

Human triage may change fixed in-domain category/severity only before substantive review, with exact revision and a structured event. Threats, harassment and distress are distinct; a triage label is not a finding of misconduct. V85 records category/severity for new history events without fabricating unknown earlier values. Queue and own receipts expose a pending linked-source appeal indicator without narrative or identities. Previously reviewed appeal snapshots cannot be replayed as new appeals.
