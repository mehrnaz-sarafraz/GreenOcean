# Educational content governance
Separate contributor scope, exact content versions, independent review, source checks, rights checks, publication, featuring and retirement. An editor is not a clinician by default; specialist attribution requires a real independently verified application/document and bounded educational scope. Every current version's content and review evidence remain distinct. No published text can be replaced while silently retaining an old approval. General editorial review is not clinical validation or accredited education.
The authoritative transition and permission contracts are ../phase-o/editorial-review-state-machine.md and ../phase-o/contributor-permissions.md. Production publication is default off until actual organizational/content/legal approval. Sources are public HTTPS references with bounded metadata and actual human review evidence. The implementation does not pretend URL syntax validation independently proves copyright ownership, scientific quality or provider availability. Course and prompt publication inherit these boundaries at O3.
