# Growth Library contract
A unified, adult-focused reviewed catalog supports books, film, documentary, music, articles, notes, guides and blank reflection templates. Discovery uses explicit query/type/topic/language choices, bounded pages and private saves; no journal, mood, diagnosis, listener transcript or social popularity personalizes it. Metadata describes creator/year where supplied, rationale, suitability, warnings, sources, rights and a deliberately opened public HTTPS availability reference. There is no streaming, unauthorized download, copied complete book/lyrics or autoplay.
New revisioned governance extends existing article/media catalogs. Historical source data and saves are preserved behind LEGACY_UNREVIEWED wrappers; unverified names/review assertions are not displayed as confirmed. Existing save tables remain authoritative for wrapped legacy resources, with a new owner-only save relation for genuinely new resource types. Retired/unavailable saves remain privately removable without exposing unavailable content. Reviewed English/Persian publication requires real qualified editorial work; none is fabricated by migration or QA fixtures.
