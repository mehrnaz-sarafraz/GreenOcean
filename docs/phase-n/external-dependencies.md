# External dependencies and release gates
Not fulfilled by synthetic CI evidence:
- Actual staffed listener shifts, independent practice/conduct supervision and supervisor availability.
- Legal/product approval for regional peer support, queue wording, no-show outcomes, processing purposes and bounded category retention.
- Real production security-key enrollment and recent-MFA operating procedures.
- Real alert recipients and delivery drills; production push/email reminder transport and user permissions where desired.
- Physical Android/iOS background/foreground, accessibility and network validation with recorded device/build evidence.
- Production backup restore and deletion replay under the approved retention policy.

No migration seeds production queue coverage. Synthetic reviewers, temporary QA TLS keys, loopback time fixtures and CI mail transport are test-only and do not count as these approvals. Durable private follow-up notes remain disabled pending an explicitly approved purpose and retention policy. No automatic launch, merge or deployment is part of Phase N.
