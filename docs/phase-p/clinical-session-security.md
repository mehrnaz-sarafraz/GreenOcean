# Clinical session boundary

The existing governed appointment is distinct from its care relationship and encounter. Each participant explicitly enters with an unrevoked authenticated session; the professional additionally needs recent security-key verification. Scheduled presence is not session activation. The professional explicitly starts within the appointment interval after both fresh entries and current consent. Cancellation, missing payment evidence or a refund obligation blocks a new paid activation. Ordinary consultation status PATCH cannot manufacture delivery.

Clinical text is encrypted with a separate configurable key ring and authenticated encounter/message/sender context. It never enters ordinary messaging, social search, journal, listener transcripts or rewards. Every read/write checks current identity, authorization and record-category policy. Messages require an active text encounter and current explicit entry; the server bounds content, cursor pages and send rate. Ending prevents further messages. Mutual acknowledgement requires server participation evidence; it does not assert a health outcome. Paid earned fees/payables accrue only after that evidence, not after a booking or payment alone.

Audio/video uses the replaceable `ClinicalMediaProvider` contract. No actual vendor, transport SDK, national health integration, prescription, recording or transcription is enabled. Admission is participant/auth-session bound, short lived and single-use; current scope and consent are checked on issuance/exchange. An adapter must enforce its audience/session binding, expiry, revocation and idempotency at the media edge. Provider-verified connectivity is separate from participant-reported trouble. A reconnect timeout becomes technical failure, not professional absence. Remote termination failure cannot undo local ending; admissions expire and the unconfirmed remote operation is audited. Actual provider reachability, contracts, residency, native permissions and device/network behavior remain launch prerequisites.
