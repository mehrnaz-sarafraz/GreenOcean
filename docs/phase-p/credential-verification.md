# Independent qualification
The original application/profile/document tables remain authoritative. A reviewer with a current staff role and recent security-key MFA records a decision against the exact application revision, after an actual human check of the profession-specific official source. Applicant and reviewer must differ. The approved origins are references for human verification, not API access, scraping permission, a successful lookup or endorsement. The system does not invent registry responses. Psychologist/counselor use the approved PCO origin; psychiatrist uses the medical register origin. A changed license/category requires correction, not silent reviewer replacement. All documents must have authenticated encryption and a configured genuine scanner CLEAN result. Legacy CLEAN labels are quarantined during migration. Qualification, platform permission and current country/modality restrictions are independent. Prescribing is absent.
